# mineralexp 
**Repositório do trabalho de conclusão de curso entitulado "Técnicas Computacionais e Inteligência Artificial na Exploração Mineral: Panoramas e Desafios".**

## Projeto de Trabalho de Conclusão de Curso
Estamos na reta final do projeto. O teste de ferramentas computacionais para exploração mineral até o momento destaca a ferramenta de análise de principais componentes (PCA) de imagens multiespectrais de satélite, aqui aplicada para hidroxilas e óxidos de ferro, e códigos de Machine Learning utilizando dados de geofísica (magnetometria, gravimetria e radiação gama). As versões finais de algoritmos Python para PCA são para execução em máquina local (medida necessária pelo tamanho dos arquivos de satélite) e estão na pasta *python*, enquanto os códigos de ML estão na pasta *jupyter_notebooks*.
