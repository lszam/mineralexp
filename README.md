# mineralexp 
**Repositório do trabalho de conclusão de curso entitulado "Técnicas Computacionais e Inteligência Artificial na Exploração Mineral: Panoramas e Desafios".**

##Status do projeto
Estamos na reta final do projeto. O teste de ferramentas computacionais para exploração mineral até o momento destaca a ferramenta de análise de principais componentes (PCA) de imagens multiespectrais de satélite, aqui aplicada para hidroxilas e óxidos de ferro. As versões finais de algoritmos Python para execução em máquina local estão na pasta *python*.
